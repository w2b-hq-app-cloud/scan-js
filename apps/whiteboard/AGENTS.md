# SCAN whiteboard agents

Reference **SCAN** notation modeler (`@spherescan/whiteboard`) - minimal OSS demo, not the Sphere product.

- Shipable open source = SCAN notation + `@spherescan/*` + this slim reference UI.
- **Sphere** (`apps/sphere` in the parent monorepo) is proprietary product chrome - do not copy it here.
- Prefer packages under `packages/*` (`@spherescan/*`) for model, viewer, modeler, and rules changes.
