# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please use one of:

1. **GitHub private security advisory** on [w2b-hq-app-cloud/scan-js](https://github.com/w2b-hq-app-cloud/scan-js/security/advisories/new)
2. Email maintainers at **security@wabloo.com** (or the contact listed in the GitHub org profile)

Do not file public issues for undisclosed vulnerabilities. We aim to acknowledge reports within 5 business days.
